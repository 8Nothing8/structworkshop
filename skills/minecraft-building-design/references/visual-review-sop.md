# 视觉评审 SOP(渲染 → 批判 → 修复)

这是补偿 AI 视觉短板的核心环节。原则:**AI 不脑补,一切以渲染图为准;视觉模型看什么,你就改什么。**

## 1. 渲染矩阵(什么视角回答什么问题)

| 视角 | 回答的问题 |
|---|---|
| `iso`(等轴 35°/22°) | 整体第一印象、体块关系、风格对不对 |
| `front` / `back` / `left` / `right` | 每面立面的开口节奏、比例、死角 |
| `top` | 屋顶收头、平面轮廓、第五立面 |
| `hero`(透视) | 人视点效果、入口、近景细节 |
| `--cut x=N`(剖面) | 内部有没有楼板/交通/功能分区 |
| `--background dark --bloom 1.0` | 夜景照明层次 |
| `--views orbit` | 环绕检查有无「只有一面能看」 |

**迭代节奏**:概念阶段只渲 `iso,front,top`(快);成型后加全 6 视角 + 剖面;收尾加 hero + 夜景。
大投影先用 `--scale 2` 快速看,定稿再 `--scale 3-4 --ssaa 3` 出图。

## 2. 一键回环

```bash
# 全流程:6 视角 + AI 批判 → review.md
python -m mcqa.review_loop build.schem --out review

# 加剖面 + 夜景
python -m mcqa.review_loop build.schem \
    --cut x=112 --cut z=112 --night --out review

# 自定义批判角度
python -m mcqa.review_loop build.schem \
    --prompt "你是结构工程师,重点找:悬浮/悬挑无支撑/跨度过大/门不配对。按坐标给修复建议。"
```

报告 `review.md` 包含:图片清单 + prompt + 视觉模型逐图描述 + 分级问题清单 + 评分。

## 3. 批判 prompt 模板

默认 prompt(脚本内置):

```
你是资深 Minecraft 建筑评审。请逐张描述你实际看到的内容(不要臆测没看到的东西),然后给出:
1. 每张图的所见描述(1-2 句/张)
2. 问题清单,每条格式:[P0致命/P1重要/P2细节] 位置或方向 + 问题 + 具体修复建议(用方块名/尺寸/坐标)
3. 整体评分 /10 及理由
只基于图片事实。结构问题(悬浮、缺失支撑、门不配对)必须结合渲染图判断。
```

**要让视觉模型聚焦**,追加一句:
- 检查轮廓:`"先只看每张图的建筑外轮廓/天际线,描述剪影形状"`
- 检查立面:`"数一下每面墙的窗洞数量与间距,指出节奏不均的地方"`
- 检查夜景:`"指出光源的分布:有没有一片死黑或一片过曝?"`
- 检查结构:`"指出任何看起来会掉下来的部分(悬挑>2格无支撑、悬浮体块、断柱)"`

## 4. 问题 → 修复词典

| 视觉模型说 | 生成器里改什么 |
|---|---|
| 墙面像噪点/花屏 | 删随机混色,结构材质统一,变化改用几何(线脚/柱线) |
| 一面墙没有窗 | 该墙的开口生成逻辑漏了这面;开口按墙遍历而非按体块 |
| 屋顶像切了一刀 | 加檐口出挑(1-2 格) + 底面倒挂台阶收边 |
| 悬浮/要掉下来 | 悬挑处加托架/柱;悬挑参数 >2 时强制加支撑 |
| 窗间距忽大忽小 | 开窗位置对齐柱网取整,不要浮点直接 cast |
| 比例奇怪(头重脚轻) | 三段式参数:基座加宽/冠部收窄,回到体块图重调 |
| 内部空的 | 楼板/楼梯/隔墙生成器没跑或只跑了一层 |
| 夜景全黑 | 内透光源间距 >4 格;加轮廓光;`--bloom` 别归零 |
| 夜景过曝一片白 | 光源密度太高(>1/16 面积);光源改嵌进墙内/加灯罩 |
| 风格混乱 | 回 style-catalog 选边,统一 palette,过渡带重做 |
| 门只有半扇 | 门必须 lower+upper 成对写,或过 `connect.py` 的 `door_pair()` |

## 5. 修复纪律

1. **每轮只修 ≤3 类问题**(P0 优先),修完立刻重渲验证 —— 一次改十个,失败就找不到原因
2. 改动先在 docstring 写「本轮改了什么、为什么」,渲染对比新旧图
3. 视觉模型说「疑似/可能」的,用 `--cut` 剖面或换角度确认,别盲改
4. P2 细节问题(单格错位、贴图选择)最后统一修,别在体块阶段抠
5. 评分连续两轮停在 8/10 以上 → 进入质量门禁验收

## 6. 成本控制

- 渲染是本地计算,贵的是视觉模型调用:小图用 `--scale 2`,一次回环 ≤8 张图
- 概念阶段可以 `--no-ai` 只渲不看 API,等体块定型再上视觉模型
- 视觉模型看 6 张 300px 小图 ≈ 看 2 张高清大图的效果,先小后大
