接口 = 面 + 面内形状 + 类型：面决定朝哪边接（法向），形状是那块「可接区域」。 它只是给装配/AI 的参考——引擎只按「面贴合 + 面内外接矩形重叠 + 类型合得来」匹配， 接口里实心还是空心完全无所谓。

备份 保存时怎么给旧版本留底
保留最近 次 同一个文件最多留 N 份旧版本
按天留存，保留最近 天 同一个文件每天最多一份
打开上限 过大的投影直接拒开，护住浏览器
文件大小上限 MB 读文件之前就拦（手滑点到 200MB 投影也不会卡死）
结构格数上限 格 画布体积 x*y*z（管“大空壳”）
方块数量上限 块 实心方块数（真正决定卡不卡）
大结构告警阈值 格 超过只在右上角提醒一下，仍然打开
备份现状
策略作用于「留底」式备份：结构保存 / 另存为（编辑器）与 mctools apply --in-place（CLI 也读同一份设置）。 删模块 / 资产包 --force 覆盖本身就是「把旧的挪到 .cache/backups」，不属本策略，也不会被「清空已有备份」动到。
